# TriKey

TriKey 将设备上的一个硬件快捷键映射为单击、双击和长按三种动作。

## 功能

- 打开微信、支付宝入口、游戏助手、系统设置、搜索、相机、录音和屏幕翻译等页面或应用
- 执行截图、返回、锁屏、状态栏和 ColorOS 识屏动作
- 切换免打扰状态；熄屏时先亮屏，在锁屏界面直接切换，无需解锁
- 配置自定义应用、Intent URI 或 Shell 命令
- 调整按键码、双击间隔和长按阈值
- 熄屏也支持快捷键跳转

## 安装与配置

1. 安装 TriKey APK。
2. 在 LSPosed 中启用模块，并将系统框架加入作用域。
3. 重启设备，使 LSPosed 加载 system_server 按键 Hook。
4. 打开 TriKey，为三种手势选择动作并保存。

默认按键码为 `780`。按键码和厂商提供的应用入口因设备而异。“替代系统原动作”默认关闭；打开后，目标按键只执行 TriKey 动作。

屏幕翻译通过 ColorOS 系统翻译组件启动全屏翻译服务。自定义 Shell 命令通过 `su -c` 以 Root 权限执行，首次使用前请在 Root 管理器中允许 TriKey；锁屏或熄屏时会先通过系统锁屏验证，单条命令最长运行 7 秒。

按键处理由硬件事件驱动，不运行常驻定时轮询。双击和长按的延时任务只在按键识别窗口内存在；熄屏唤醒使用屏幕亮起事件，并保留一次性超时兜底。
