# TriKey

把设备硬件快捷键设为单击、双击和长按三种手势，并为每种手势选择要执行的动作。

## 功能

- 打开微信、支付宝入口、系统设置、搜索、相机、录音等页面或应用
- 执行截图、返回、锁屏、状态栏和 ColorOS 识屏动作
- 配置自定义应用或 Intent URI
- 调整按键码、双击间隔和长按阈值
- 可选地在熄屏时唤醒屏幕并继续执行跳转

熄屏唤醒默认关闭。开启后，未设置 PIN、图案或密码的设备会继续打开目标；设置了安全锁屏时，TriKey 只点亮屏幕并暂存本次动作，系统确认用户解锁后才执行。此功能不跳过或模拟凭据验证。截图、返回、锁屏和状态栏操作保留原有即时行为。待执行动作会在设备再次熄屏或两分钟后取消。

## 安装与设置

1. 安装 TriKey APK。
2. 在 LSPosed 中启用模块，并按模块作用域配置系统框架。
3. 重启设备以加载系统按键 Hook。
4. 打开 TriKey，设置按键码、手势动作和所需选项，然后保存。

默认按键码为 `780`。不同机型和系统版本可能使用不同按键码；“替代系统原动作”默认关闭，只有需要屏蔽原有快捷动作时才开启。

## Android 兼容性

应用最低安装版本为 Android 8.0（API 26）。本项目以 Android 15（API 35）及以上系统为兼容目标，并根据设备运行时提供的系统 API 选择唤醒实现，不把逻辑绑定到单一 Android 大版本。当前已在 Android 17 / ColorOS 17 设备上完成模块加载和按键动作验证；Android 15 真机验证仍需对应设备。

硬件按键入口优先使用 ColorOS 系统 Hook，并提供 AOSP 系统策略回退。实际按键码和预设应用入口由厂商及已安装应用决定，因此并非所有预设动作都适用于所有 Android 设备。

## 构建

在仓库根目录运行：

```sh
./gradlew :app:testDebugUnitTest :app:lintRelease :app:assembleRelease
```

GitHub Actions 会运行单元测试、Lint 并构建 APK。带签名配置的版本标签会发布到 GitHub Releases，APK 文件名使用 `TriKey-v版本号.apk`。
